## 2. Cara pakai untuk admin

### Mengisi profil & WhatsApp

1. Login sebagai owner/admin.
2. Buka **Pengaturan → Landing page & katalog publik**.
3. Isi nomor WhatsApp admin, alamat, tagline, deskripsi, dan fasilitas.
4. Simpan profil.

### Mengunggah foto kamar

1. Buka **Status Kamar**.
2. Klik **Tambah foto** pada kartu kamar.
3. Pilih JPG/PNG/WebP. Foto otomatis dikompres.
4. Simpan.

### Mempublikasikan katalog

1. Buka **Pengaturan → Landing page & katalog publik**.
2. Masukkan **Kunci publikasi katalog**.
3. Klik **Publikasikan katalog**.
4. Buka **Lihat Landing Page** untuk memeriksa hasilnya.

Kunci publikasi tersimpan di file lokal `.env.catalog` (di-ignore Git) dan di
environment Vercel `CATALOG_ADMIN_KEY`. Jangan membagikan kunci ini.

### Notifikasi dashboard

- **Akan Berakhir**: kontrak aktif dengan `endDate` ≤ 7 hari dari hari ini
  (termasuk yang sudah lewat).
- **Menunggak**: penghuni aktif dengan tagihan `unpaid` yang `dueDate`-nya
  hari ini atau sebelumnya. Lama tunggakan dihitung dari jatuh tempo paling
  lama. Contoh tampilan: *Menunggak 2 hari*.
- Setelah tagihan diverifikasi lunas, entri otomatis hilang karena dashboard
  membaca status tagihan, bukan menyimpan notifikasi terpisah.

## 3. Arsitektur katalog publik

Data operasional tetap **local-first** di `localStorage`. Agar pengunjung di
perangkat lain bisa melihat katalog yang sama, admin memublikasikan snapshot
ke backend ringan:

```text
Admin (localStorage)
  │  Publikasikan katalog
  ▼
POST /api/catalog          → tabel casa_catalog (Postgres)
POST /api/catalog/photo    → tabel casa_catalog_photos (Postgres)
  │
  ▼
Pengunjung casaramire.com
  GET /api/catalog → render katalog + foto
```

Snapshot publik **tidak** memuat data penghuni, tagihan, password, atau kunci
admin. Hanya properti, harga, kamar, dan URL foto.

Endpoint memakai `pg` dan environment Vercel yang sudah tersedia:

```text
POSTGRES_URL / POSTGRES_URL_NON_POOLING
CATALOG_ADMIN_KEY
```

Tabel dibuat otomatis saat endpoint pertama kali dipanggil
(`create table if not exists`).

## 6. Deployment

Push ke `main` memicu deploy Vercel otomatis. Setelah deploy, cek:

```text
https://www.casaramire.com/            → landing page
https://www.casaramire.com/#/login     → login admin
https://www.casaramire.com/api/catalog → JSON katalog (harus 200)
```

Jika `/api/catalog` mengembalikan 503, periksa environment Postgres di Vercel.
Landing page tetap tampil dengan data lokal/seed sebagai fallback.
