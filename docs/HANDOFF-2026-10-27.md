## 2. Cara pakai untuk admin

### Mengisi profil & WhatsApp

1. Login sebagai owner/admin.
2. Buka **Pengaturan → Landing page & katalog publik**.
3. Isi nomor WhatsApp admin, alamat, tagline, deskripsi, dan fasilitas.
4. Simpan profil.

### Mengunggah foto kamar

1. Buka **Status Kamar**.
2. Klik **Tambah foto** pada kartu kamar.
3. Pilih JPG/PNG/WebP. Foto otomatis dikompres.
4. Simpan.

### Mempublikasikan katalog

1. Buka **Pengaturan → Landing page & katalog publik**.
2. Masukkan **Kunci admin** (nilai `CATALOG_ADMIN_KEY`).
3. Klik **Publikasikan katalog**.
4. Buka **Lihat Landing Page** untuk memeriksa hasilnya.

Kunci admin tersimpan di file lokal `.env.catalog` (di-ignore Git) dan di
environment Vercel `CATALOG_ADMIN_KEY`. Kunci yang sama dipakai untuk
sinkronisasi state dan pembuatan link DOKU. Jangan membagikan kunci ini.

### Membuat link pembayaran DOKU

1. Untuk tagihan: buka **Sewa & Verifikasi Kas**, klik **Link DOKU**.
2. Untuk invoice layanan: buka **Financial → Invoice**, klik **Link DOKU**.
3. Untuk perpanjangan: buka **Dashboard → Akan Berakhir → Perpanjang**, lalu
   klik **Buat Link DOKU** di form perpanjangan.
4. Salin link atau klik **Kirim via WhatsApp**.
5. Setelah penghuni membayar, status berubah otomatis. Tidak perlu verifikasi
   manual.

Jika link perpanjangan sudah dikirim, penyewa pindah ke kartu **Menunggu
Pembayaran Perpanjangan**. Setelah dibayar, kontrak otomatis diperpanjang dan
kartu tersebut hilang. Jika link kedaluwarsa/tidak dibayar, penyewa kembali
muncul di **Akan Berakhir**.

### Reset password owner

1. Di halaman login, klik **Lupa password?**.
2. Isi username owner, password baru, konfirmasi, dan **kunci admin**.
3. Klik **Reset password**, lalu login dengan password baru.

Reset hanya berlaku di browser/perangkat tersebut.

### Notifikasi dashboard

- **Akan Berakhir**: kontrak aktif dengan `endDate` ≤ 7 hari dari hari ini
  (termasuk yang sudah lewat).
- **Menunggu Pembayaran Perpanjangan**: penyewa yang sudah dibuatkan link DOKU
  perpanjangan. Mereka sementara keluar dari daftar Akan Berakhir agar tidak
  dikirimi link ganda.
- **Menunggak**: penghuni aktif dengan tagihan `unpaid` yang `dueDate`-nya
  hari ini atau sebelumnya. Lama tunggakan dihitung dari jatuh tempo paling
  lama. Contoh tampilan: *Menunggak 2 hari*.
- Setelah tagihan diverifikasi/dibayar, entri Menunggak otomatis hilang karena
  dashboard membaca status tagihan, bukan menyimpan notifikasi terpisah.
- Setelah link perpanjangan dibayar, kontrak otomatis diperpanjang dan entri
  Menunggu Pembayaran hilang. Jika link kedaluwarsa, penyewa kembali ke Akan
  Berakhir.

## 3. Arsitektur katalog publik

Data operasional tetap **local-first** di `localStorage`. Agar pengunjung di
perangkat lain bisa melihat katalog yang sama, admin memublikasikan snapshot
ke backend ringan:

```text
Admin (localStorage)
  │  Publikasikan katalog
  ▼
POST /api/catalog          → tabel casa_catalog (Postgres)
POST /api/catalog/photo    → tabel casa_catalog_photos (Postgres)
  │
  ▼
Pengunjung casaramire.com
  GET /api/catalog → render katalog + foto
```

Snapshot publik **tidak** memuat data penghuni, tagihan, password, atau kunci
admin. Hanya properti, harga, kamar, dan URL foto.

Endpoint memakai `pg` dan environment Vercel yang sudah tersedia:

```text
POSTGRES_URL / POSTGRES_URL_NON_POOLING
CATALOG_ADMIN_KEY
```

Tabel dibuat otomatis saat endpoint pertama kali dipanggil
(`create table if not exists`).

## 3b. Pembayaran DOKU otomatis

### Alur

```text
Admin klik Link DOKU
  → POST /api/payments/doku/create
  → payment intent PENDING + link DOKU
  → link dikirim ke penghuni (WhatsApp)
  → penghuni bayar di halaman DOKU
  → POST /api/payments/doku/notification
       verifikasi signature HMAC
       update casa_payments = PAID
       update casa_state (bill/invoice lunas, atau kontrak diperpanjang)
  → aplikasi admin poll /api/state (15 detik / saat tab aktif)
  → dashboard & notifikasi otomatis berubah
```

### Yang sudah diimplementasikan

- Tombol **Link DOKU** di:
  - daftar tagihan (`Sewa & Verifikasi Kas`),
  - invoice layanan (`Financial`),
  - kartu **Menunggak** di dashboard,
  - form **Perpanjang** (`Buat Link DOKU`).
- Modal link dengan tombol salin, buka halaman DOKU, dan kirim WhatsApp.
- Webhook `/api/payments/doku/notification`:
  - verifikasi signature terhadap raw body,
  - idempotent (notifikasi ganda tidak menggandakan pembayaran),
  - mendukung pembayaran sebagian (bill tetap belum lunas jika nominal kurang),
  - menandai bill/invoice lunas,
  - memperpanjang kontrak dan membuat bill perpanjangan lunas.
- Sinkronisasi state lewat `/api/state`:
  - stateAdminKey memakai `CATALOG_ADMIN_KEY`,
  - client push debounce + poll 15 detik,
  - versi server mencegah overwrite saat webhook masuk,
  - `replaceState` lokal mempertahankan user/session/kunci admin/foto lokal.
- Toasts otomatis saat pembayaran DOKU diterima atau kontrak diperpanjang.

### Hasil uji di production

- `npm test` → **29 test lulus**.
- `npm run build` → sukses.
- Landing page live → 42 kartu kamar, tombol WhatsApp muncul, tanpa error console.
- `GET /api/state` tanpa kunci → `401`.
- `PUT + GET + DELETE /api/state` → berhasil.
- Webhook signature valid → `200 {"responseCode":"2000700"}`.
- Webhook signature salah → `401`.
- Simulasi pembayaran tagihan:
  - bill `unpaid` → `paid`
  - `tenant.totalPaid` naik
  - payment history bertambah
  - state version naik
- Simulasi pembayaran perpanjangan:
  - `endDate` maju dari `2026-10-29` → `2026-11-29`
  - bill `Perpanjangan` lunas dibuat
  - `contractTotal` dan `totalPaid` bertambah
- Uji link perpanjangan di UI:
  - penyewa masuk ke **Menunggu Pembayaran Perpanjangan**
  - tombol **Buka link** menampilkan link yang tersimpan
  - tombol **Batalkan** mengembalikan penyewa ke **Akan Berakhir**
- Uji reset password owner:
  - kunci salah → pesan **“Kunci admin tidak valid.”**
  - kunci benar → password berhasil direset
  - login dengan password baru → masuk dashboard
- State uji sudah dihapus setelah pengujian, jadi server bersih dan siap
  menerima state asli dari browser admin saat kunci dimasukkan.

### Blocker saat ini

Akun DOKU baru belum mengaktifkan channel. Uji create checkout untuk QRIS,
VA, dan e-wallet semuanya mengembalikan `PAYMENT CHANNEL IS INACTIVE`.
Aktifkan channel di DOKU Back Office, lalu daftarkan notification URL:

```text
https://www.casaramire.com/api/payments/doku/notification
```

Kalau hanya sebagian channel yang aktif, batasi daftar channel lewat
environment Vercel:

```text
DOKU_PAYMENT_CHANNELS=QRIS,VIRTUAL_ACCOUNT_BCA,EMONEY_DANA
```

Tanpa variabel ini, aplikasi meminta semua channel default ke DOKU. Jika ada
satu saja yang nonaktif, DOKU bisa menolak pembuatan checkout.

## 3c. Fitur lupa password owner

Halaman login memiliki tombol **Lupa password?** untuk mereset password owner
tanpa harus menghapus data.

Cara pakai:

1. Buka halaman login, klik **Lupa password?**.
2. Isi username owner, password baru, konfirmasi, dan **kunci admin**.
3. Klik **Reset password**.
4. Login dengan password baru.

Kunci admin yang dipakai adalah `CATALOG_ADMIN_KEY` — kunci yang sama untuk
sinkronisasi, publikasi katalog, dan pembuatan link DOKU. Nilainya ada di
`.env.catalog` atau environment Vercel.

Catatan:

- Reset hanya berlaku di browser/perangkat tempat reset dilakukan, karena
  data akun disimpan di `localStorage`.
- Reset mandiri hanya untuk akun **owner**. Password staf direset oleh owner
  lewat **Manajemen Akun**.
- Jika kunci admin tidak tersedia, reset tidak bisa dilakukan. Simpan kunci
  tersebut di tempat aman.

```text
https://www.casaramire.com/                              → landing page
```

Jika `/api/catalog` atau `/api/state` mengembalikan 503, periksa environment
Postgres di Vercel. Landing page tetap tampil dengan data lokal/seed sebagai
fallback.

## 7. Keamanan & kredensial

- `CATALOG_ADMIN_KEY` adalah kunci admin: dipakai untuk publikasi katalog,
  sinkronisasi state, pembuatan link DOKU, dan reset password owner. Jangan
  dibagikan.
- Kunci admin tersimpan di `.env.catalog` (lokal, di-ignore Git) dan di
  Vercel Environment Variables.
- Kredensial DOKU tersimpan di `.env.doku` (lokal, di-ignore Git) dan di
  Vercel. Secret key tidak pernah ditaruh di bundle frontend.
- Webhook DOKU diverifikasi dengan signature HMAC; notifikasi tanpa signature
  valid ditolak.
- State API dilindungi `x-admin-key`.
- Snapshot katalog publik tidak memuat data penghuni, tagihan, password, atau
  kunci admin.
- Password owner/staf disimpan sebagai hash SHA-256 bersalt di `localStorage`
  perangkat. Reset password hanya berlaku di perangkat tersebut.
