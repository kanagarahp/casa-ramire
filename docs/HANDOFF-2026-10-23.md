## 3. Stack dan keputusan teknis

- **Vite 8** untuk build dan dev server.
- **Tailwind CSS 4** lewat plugin `@tailwindcss/vite`; token desain ada di
  `src/styles.css`.
- **Vanilla ES modules** — tanpa framework UI.
- **Lucide** untuk ikon.
- **Hash routing** (`#/dashboard`, `#/rooms`, dst.) supaya tidak perlu rewrite
  SPA di hosting statis.
- `vite.config.js` memakai `base: './'` agar build portabel di root domain
  maupun sub-path seperti GitHub Pages.
- **Tidak ada backend/database.** Semua operasi berjalan di browser.
- State disimpan di `localStorage` dengan key `casa-ramire:state`.
- Session login disimpan di `casa-ramire:session`.
- Schema state saat ini: `SCHEMA_VERSION = 2` (`src/core/constants.js`).

## 5. Aturan bisnis yang perlu dijaga

- **Deposit adalah kewajiban**, bukan pendapatan.
- **Pendapatan sewa diakui secara accrual** sebesar biaya bulanan kontrak.
- Pembayaran sewa di atas biaya bulanan dicatat sebagai **pendapatan dimuka**
  (deferred revenue), bukan pendapatan langsung.
- Diskon rupiah dihitung **per bulan kontrak**.
- Diskon persen dihitung dari total sewa.
- Add-on dihitung per bulan dan masuk ke biaya bulanan penghuni.
- Tagihan yang sudah diverifikasi dapat dibatalkan; saldo penghuni ikut
  disesuaikan.
- Check-out mengakhiri kontrak dan mengembalikan kamar ke status tersedia.
- Pindah kamar menyimpan riwayat hunian.
- Perpanjangan kontrak membuat kontrak baru dan menutup periode lama.
- Data awal: **42 kamar** (201–221 dan 301–321), semuanya kosong.

## 9. Catatan penting / jebakan

1. **Jangan commit data pengguna.** Data ada di `localStorage`, bukan di repo.
2. **Jangan commit `.vercel/` atau `.env.local`.** Keduanya berisi konteks
   project/token OIDC.
3. **Jangan membuat project Vercel baru.** Gunakan project `casa-ramire` yang
   sudah terhubung ke GitHub dan domain.
4. **Jangan mengubah nameserver** tanpa memindahkan record MX/TXT jika email
   `@casaramire.com` dipakai.
5. **Hash routing** berarti URL seperti `#/dashboard` tidak butuh rewrite server.
6. **Vercel deployment protection** dapat meminta login Vercel untuk URL
   deployment/preview tertentu. Domain custom `www.casaramire.com` tetap publik.
7. **Node 24.x** adalah runtime Vercel saat ini. `.nvmrc` 22 hanya panduan lokal.
8. **GitHub Actions** belum aktif karena scope token; jangan buang waktu
   menambahkan workflow sebelum scope `workflow` tersedia.
9. **Password demo** hanya untuk demo. Untuk produksi multi-user, butuh backend
   autentikasi dan database.
10. **Data tidak tersinkron** antar browser/perangkat. Jika owner membuka di HP
    dan laptop, datanya terpisah.
