## 2. Kalender harga & ketersediaan kamar VIP

### Menu owner: Atur Kamar VIP
Menu owner-only baru: **Atur Kamar VIP**.

Fitur:
- Kalender per tanggal untuk kamar 101.
- Setiap tanggal dapat diatur:
  - **Buka untuk dijual**,
  - **Tutup / dipakai sendiri**,
  - **Harga khusus**,
  - **Catatan** (mis. Weekend, Peak season, Dipakai sendiri).
- **Harga default harian** dapat diubah dari halaman ini.
- **Atur cepat rentang tanggal**:
  - pilih tanggal mulai & selesai,
  - pilih status buka/tutup,
  - isi harga khusus,
  - isi catatan.
- Daftar semua harga/tanggal khusus dapat diedit atau dihapus.
- Tombol **Hapus semua pengaturan** untuk kembali ke harga default dan
  tersedia setiap hari.

### Perhitungan harga
- Harga harian kamar 101 dihitung **per malam**.
- Tanggal tanpa harga khusus memakai harga default.
- Tanggal dengan harga khusus memakai harga tersebut.
- Contoh:
  - Jumat–Minggu Rp350.000/malam,
  - Senin–Kamis Rp250.000/malam,
  - tanggal peak season Rp500.000/malam.

### Validasi tanggal
- Tanggal yang ditutup owner:
  - tidak bisa dipilih di landing page,
  - ditolak oleh form booking admin,
  - ditolak juga oleh server saat booking online dikirim.
- Jika tamu memilih rentang tanggal yang mengandung tanggal tutup, sistem
  menampilkan tanggal yang bermasalah.
- Pindah booking ke kamar 101 juga divalidasi terhadap kalender.

### Data & migrasi
- `SCHEMA_VERSION` naik ke **11**.
- `rooms[].dailyCalendar` menyimpan pengaturan per tanggal:
  ```json
  {
    "2026-11-21": {
      "available": true,
      "price": 350000,
      "note": "Weekend"
    },
    "2026-11-25": {
      "available": false,
      "price": 0,
      "note": "Dipakai sendiri"
    }
  }
  ```
- Kalender ikut tersinkron ke server dan tersedia di endpoint publik
  `/api/availability`.

## 5. Deposit & pembayaran transfer Mandiri

### Deposit
- Deposit dijelaskan di landing page dengan ikon **“i”**.
- Deposit:
  - dibayar di awal bersama sewa,
  - bukan biaya sewa,
  - **dikembalikan saat check-out** sesuai ketentuan.
- Total yang perlu dibayar = **total sewa + deposit**.
- Checkbox lama **“Deposit sudah dibayar / diterima”** dihapus.
- Deposit tidak lagi dicatat sebagai langkah terpisah saat check-in.

### Rekening pembayaran
Rekening default yang tampil di landing page, email, dan tagihan:

- **Bank Mandiri**
- **No. Rekening: 700013745877**
- **a.n. ERNY KURNIAWATI**

Rekening dapat diubah owner di:
**Pengaturan → Pembayaran & tagihan email**.

### QRIS & Virtual Account
- Opsi **QRIS** dan **Virtual Account** dihapus dari pilihan pembayaran manual.
- Metode manual yang tersedia sekarang:
  - **Transfer Bank Mandiri**
  - **Tunai / Cash**
- DOKU tetap opsional dan nonaktif secara default. Jika diaktifkan nanti,
  kanal pembayaran mengikuti pengaturan akun DOKU.

### Alur pembayaran booking
1. Tamu booking online.
2. Modal sukses menampilkan:
   - total sewa,
   - deposit,
   - total transfer,
   - Bank Mandiri 700013745877 a.n. ERNY KURNIAWATI,
   - tombol salin nomor rekening,
   - tombol kirim bukti transfer ke WhatsApp admin.
3. Tamu transfer.
4. Admin membuka **Status Kamar / Booking Harian → Verifikasi**.
5. Jika dana masuk:
   - klik **Verifikasi & Tandai Lunas**,
   - sewa + deposit ditandai lunas,
   - email konfirmasi dikirim ke tamu + salinan admin.
6. Jika belum bayar:
   - klik **Follow Up Pembayaran**,
   - sistem mengirim pengingat berisi nominal dan rekening.
7. Verifikasi bisa dibatalkan jika transfer ternyata salah.

## 7. Email notifikasi

### Booking online
- Email dikirim ke tamu dan email admin default.
- Isi email:
  - kode booking,
  - data tamu,
  - kamar & tanggal,
  - total sewa,
  - deposit,
  - total transfer,
  - rekening Mandiri.

### Tagihan
- Tagihan dari **POS**, **Buat Tagihan**, dan **Invoice Layanan** langsung
  dikirim ke email penerima + salinan admin.
- Jika email penerima belum diisi, tagihan tetap tersimpan dan admin mendapat
  peringatan.

### Pengingat H-7
- Cron Vercel berjalan setiap hari pukul **08.00 WIB**.
- Mengirim pengingat untuk tagihan yang jatuh tempo 7 hari lagi.
- Bisa dipicu manual dari **Pengaturan → Kirim pengingat H-7**.
- Email memuat rekening Mandiri.

### Konfirmasi pembayaran
- Verifikasi pembayaran tagihan/invoice/booking mengirim email konfirmasi.
- DP/deposit yang tercatat juga masuk ke email booking.

### Konfigurasi email
- Provider: **Resend**.
- Env Vercel:
  - `RESEND_API_KEY`
  - `EMAIL_FROM`
  - `NOTIFICATION_EMAIL` = `casaramirejogja@gmail.com`
  - `EMAIL_REPLY_TO` = `casaramirejogja@gmail.com`
  - `CRON_SECRET`
- Email tes pernah dikirim dan API Resend merespons sukses.

## 8. Perbaikan Booking Online

- Permintaan booking landing page tersimpan di tabel `casa_bookings`.
- Menu Booking Online:
  - memuat ulang otomatis setiap 20 detik,
  - menampilkan notice jika kunci admin belum diisi / tidak cocok.
- Jika server/database error 5xx, permintaan tamu disimpan lokal agar tidak
  hilang.
- Endpoint publik `/api/availability` melakukan normalisasi state agar kamar
  101 dan data kalender tetap muncul meski perangkat admin belum sinkron.
- Validasi server untuk booking online:
  - ketersediaan kamar,
  - tipe sewa harian/bulanan,
  - tanggal yang ditutup owner,
  - kapasitas parkir mobil.

### Kunci admin
Kunci admin adalah kunci API server, bukan password login:

- Disimpan di Vercel env `CATALOG_ADMIN_KEY`.
- Dimasukkan sekali di **Pengaturan → Kunci admin** pada setiap browser admin.
- Dipakai untuk:
  - sinkronisasi state,
  - memuat Booking Online,
  - publikasi katalog,
  - email dari browser,
  - link pembayaran DOKU.
- Tanpa kunci ini, booking tetap masuk ke server tetapi tidak muncul di panel
  admin, dan cron H-7 tidak punya state untuk diproses.

  benar-benar diaktifkan.

  sesuai ketentuan.
